실습 1

떨어지는 공 — 중력과 속도

학습 목표

중력이 속도를 바꾸고, 속도가 위치를 바꾼다는 것을 코드로 표현한다.

생활 속 예시

책상에서 떨어진 지우개, 나무에서 떨어지는 사과

핵심 개념

속도 ← 속도 + 중력×시간
위치 ← 위치 + 속도×시간

예제 코드

lab1_falling_ball.py GlowScript에서 실행하기 ↗ 
Web VPython 3.2
# 바닥과 공 만들기
ground = box(pos=vec(0,-5,0), size=vec(10,0.2,4), color=color.green)
ball = sphere(pos=vec(0,5,0), radius=0.5, color=color.red, make_trail=True)

g = vec(0,-9.8,0)      # 중력 가속도 (m/s²)
ball.v = vec(0,0,0)    # 처음 속도: 멈춰 있음
dt = 0.01              # 한 번에 흐르는 시간 (초)
t = 0

# 공이 바닥에 닿기 전까지 반복
while ball.pos.y - ball.radius > ground.pos.y:
    rate(100)
    ball.v = ball.v + g*dt          # 중력이 속도를 바꾼다
    ball.pos = ball.pos + ball.v*dt # 속도가 위치를 바꾼다
    t = t + dt

print("바닥에 닿은 시간:", round(t,2), "초")

실습 2

튀어 오르는 공 — 바닥 충돌과 반발

학습 목표

조건문(if)으로 충돌을 감지하고, 속도 방향을 뒤집어 튀어 오르게 한다.

생활 속 예시

농구공 드리블, 탁구공이 점점 낮게 튀는 모습

핵심 개념

반발 계수 e (0~1)
튀어 오른 속도 = −e × 부딪힌 속도

예제 코드

lab2_bouncing_ball.py GlowScript에서 실행하기 ↗ 
Web VPython 3.2
ground = box(pos=vec(0,-5,0), size=vec(10,0.2,4), color=color.green)
ball = sphere(pos=vec(0,4,0), radius=0.5, color=color.orange, make_trail=True)

g = vec(0,-9.8,0)
ball.v = vec(0,0,0)
e = 0.8                # 반발 계수: 1에 가까울수록 잘 튄다
dt = 0.01
t = 0
floor = ground.pos.y + ground.size.y/2   # 바닥 윗면 높이

while t < 10:           # 10초 동안 관찰
    rate(100)
    ball.v = ball.v + g*dt
    ball.pos = ball.pos + ball.v*dt

    # 공이 바닥에 닿았다면?
    if ball.pos.y - ball.radius < floor:
        ball.pos.y = floor + ball.radius  # 바닥에 파묻히지 않게
        ball.v.y = -e * ball.v.y          # 위로 튀어 오른다

    t = t + dt

실습 3

던진 공의 포물선 운동 — 수평·수직 속도

학습 목표

처음 속도를 가로·세로로 나누고, 던지는 각도에 따라 날아가는 거리가 달라짐을 확인한다.

생활 속 예시

농구 슛, 멀리 던지기, 분수대 물줄기

핵심 개념

가로 속도 = 속력×cos(각도)
세로 속도 = 속력×sin(각도)

예제 코드

lab3_projectile.py GlowScript에서 실행하기 ↗ 
Web VPython 3.2
scene.center = vec(12,5,0)       # 카메라가 볼 중심
ground = box(pos=vec(15,-0.1,0), size=vec(40,0.2,6), color=color.green)
ball = sphere(pos=vec(0,0,0), radius=0.4, color=color.cyan, make_trail=True)

speed = 15             # 던지는 속력 (m/s)
angle = 45             # 던지는 각도 (도)
theta = radians(angle)
ball.v = vec(speed*cos(theta), speed*sin(theta), 0)

g = vec(0,-9.8,0)
dt = 0.01
t = 0

# 공이 땅(높이 0)보다 위에 있는 동안 반복
while ball.pos.y >= 0:
    rate(100)
    ball.v = ball.v + g*dt
    ball.pos = ball.pos + ball.v*dt
    t = t + dt

print("날아간 거리:", round(ball.pos.x,1), "m")
print("비행 시간:", round(t,2), "초")
